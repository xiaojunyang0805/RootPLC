# Agent package

Everything an agent host needs to use RootPLC.

| Path | Contents |
|---|---|
| `skills/` | SKILL.md set (agentskills.io format) |
| `templates/AGENTS.md` | Written into new projects by `rootplc init` |
| `mcp/` | MCP config snippets per host, Western and Chinese |
| `plugins/claude-code/` | Claude Code plugin (MCP server + skills); marketplace in `/.claude-plugin/` |
| `plugins/codex/` | Codex plugin (later) |
