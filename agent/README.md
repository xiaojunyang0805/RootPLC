# Agent package

Everything an agent host needs to use RootPLC (Phase 1).

| Path | Contents |
|---|---|
| `skills/` | SKILL.md set (agentskills.io format) |
| `templates/AGENTS.md` | Written into new projects by `rootplc init` |
| `mcp/` | MCP config snippets per host, Western and Chinese |
| `plugins/` | Claude Code and Codex plugins |
