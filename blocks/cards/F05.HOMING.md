# F05.HOMING · `RB_Homing`

**Family:** F05 sequencing · **Level:** L1 elementary function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Homes an axis that has only a home switch (a positioning motor, a lift, a
turntable, an indexer): move towards the switch, then back away slowly
until it releases; that edge is the reference. Servo axes home with the
RootMotion library instead.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Start` | in | BOOL | FALSE | rising edge: home |
| `Abort` | in | BOOL | FALSE | TRUE: stop now |
| `HomeSwitch` | in | BOOL | FALSE | the home switch |
| `Timeout` | in | TIME | T#30s | per phase |
| `Reset` | in | BOOL | FALSE | rising edge clears a fault |
| `MoveToHome` / `MoveAway` | out | BOOL | | direction commands |
| `Slow` | out | BOOL | | creep speed (while backing off) |
| `Homed` | out | BOOL | | the reference is valid |
| `Busy` | out | BOOL | | homing |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F05.homing.seek]** A rising edge of `Start` (no fault, no `Abort`)
   clears `Homed` and moves towards the switch; on the switch already, it
   goes straight to backing off.
2. **[F05.homing.back-off]** On the switch it moves away slowly; when the
   switch releases the axis is `Homed` and the outputs go off.
3. **[F05.homing.timeout]** Each phase must finish within `Timeout`
   (restarted at every phase and every start): fault 1 seeking, 2 backing
   off. Outputs off (safe state); no start until `Reset`.
4. **[F05.homing.abort]** `Abort` TRUE stops at once; the axis is not
   homed.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | the home switch was not reached within `Timeout` | `Reset` |
| 2 | the home switch did not release within `Timeout` | `Reset` |

## Tests

`conformance/cases/blocks/ok_rb_round4.st` (`homing_*`). Library mutation score against all block tests: 99% (1350 of 1356 library mutants, 6 Nov 2026; the six survivors are equivalent mutants in `RB_MotorReversing`, `RB_AlarmSummary`, `RB_Trips` and `RB_PID`).

## Combines with

`RB_MotorReversing` (`MoveToHome`/`MoveAway` as the two directions),
`RB_Drive` (`Slow` selects a preset speed), `RB_ModeManager`
(`AutoAllowed` needs `Homed`), `RB_StepChain`.

## Not covered

An encoder reference mark, homing with a second slow approach, losing
`Homed` on power-down (the application clears it by homing again).
