# F01.DEADBAND · `RB_Deadband`

**Family:** F01 signal conditioning · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Holds the output until the input has moved more than `Deadband` away from
it, so that noise does not make downstream logic, logging or communication
chatter.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `In` | in | REAL | | value |
| `Deadband` | in | REAL | 0 | change needed before `Out` follows |
| `Out` | out | REAL | | held value |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F01.deadband.start]** In the first call `Out` = `In`.
2. **[F01.deadband.hold]** `Out` takes the value of `In` only when
   `|In - Out|` > `Deadband`; a change of exactly `Deadband` is held.

## Tests

## Combines with

F11 report-by-exception communication, F08 alarms on analog values,
F06 controllers that should not react to noise.

## Not covered

A deadband around zero that forces small values to 0 (use `LIMIT` and
`ABS`), hysteresis switches (F06 on/off control).
