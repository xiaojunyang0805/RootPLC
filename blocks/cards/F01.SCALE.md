# F01.SCALE · `RB_Scale`

**Family:** F01 signal conditioning · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Converts a raw value (counts, mA, V) to engineering units along a straight
line, and supervises the raw range (for example a broken 4–20 mA wire).

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Raw` | in | REAL | | raw value |
| `RawMin` / `RawMax` | in | REAL | 0.0 / 100.0 | raw range (either order) |
| `EngMin` / `EngMax` | in | REAL | 0.0 / 100.0 | engineering values at `RawMin` / `RawMax` (falling lines allowed) |
| `Margin` | in | REAL | 0.0 | raw tolerance outside the range before a fault |
| `Clamp` | in | BOOL | TRUE | keep `Value` within the engineering range |
| `Reset` | in | BOOL | FALSE | rising edge clears a fault |
| `Value` | out | REAL | | engineering value |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F01.scale.line]** `Value = EngMin + (Raw - RawMin) * (EngMax - EngMin) / (RawMax - RawMin)`.
2. **[F01.scale.clamp]** With `Clamp`, `Value` stays between `EngMin` and
   `EngMax` (whichever is smaller is the lower limit).
3. **[F01.scale.range]** `Raw` more than `Margin` below the raw range is
   fault 2, more than `Margin` above it fault 3; exactly at the margin is
   valid. `RawMin = RawMax` is fault 1.
4. **[F01.scale.fault]** A fault latches; while it lasts `Value` keeps the
   last valid value (safe state: substitute value). A rising edge of
   `Reset` clears it.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | invalid range (`RawMin = RawMax`) | `Reset` after correcting the range |
| 2 | below range (for example wire break on 4–20 mA) | `Reset` |
| 3 | above range | `Reset` |
