# F02.PERMISSIVES · `RB_Permissives`

**Family:** F02 discrete logic and interlocks · **Level:** L1 elementary
function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Combines up to 16 start conditions (guards closed, air pressure, oil
level, ...) into one `Ok` and tells the operator which one dropped first
(first-out), the usual answer to "why won't it start?".

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Cond` | in | ARRAY[1..16] OF BOOL | | conditions |
| `Used` | in | WORD | 16#FFFF | bit k−1 set: condition k is used |
| `Reset` | in | BOOL | FALSE | rising edge clears `FirstOut` when all are TRUE |
| `Ok` | out | BOOL | | every used condition is TRUE |
| `Missing` | out | INT | | used conditions that are FALSE |
| `FirstOut` | out | INT | | the first condition that dropped; 0: none |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F02.perm.ok]** `Ok` when every used condition is TRUE; unused ones
   are ignored.
2. **[F02.perm.first-out]** `FirstOut` is the first used condition that
   was FALSE (the lowest number when several drop in the same call) and
   keeps that value.
3. **[F02.perm.reset]** A rising edge of `Reset` clears `FirstOut` only
   when all used conditions are TRUE again.

## Tests

`conformance/cases/blocks/ok_rb_data_logic.st` (`permissives_*`). Library mutation score against all block tests: 99% (1259 of 1265 library mutants, 6 Nov 2026; the six survivors are equivalent mutants in `RB_MotorReversing`, `RB_AlarmSummary`, `RB_Trips` and `RB_PID`).

## Combines with

`RB_StartStop` and F04 device modules (`Permissive`), `RB_ModeManager`
(`AutoAllowed`), HMI messages for `FirstOut`, F08 alarms.

## Not covered

Interlocks that stop a running machine (use `Interlock` inputs), more than
16 conditions (cascade two blocks).
