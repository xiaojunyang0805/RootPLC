# F11.RECIPE · `RB_RecipeTable`

**Family:** F11 data handling · **Level:** L1 elementary function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Loads a recipe (8 parameters: amounts, temperatures, times) by number from
a table of 16, and saves the parameters in use back into the table. The
table belongs to the application (a `VAR_IN_OUT`), so it decides where it
lives: a RETAIN variable, a file, the HMI.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Number` | in | INT | 1 | recipe 1 … 16 |
| `Load` | in | BOOL | FALSE | rising edge: `Params` := table row |
| `Save` | in | BOOL | FALSE | rising edge: table row := `Actual` |
| `Actual` | in | ARRAY[1..8] OF REAL | | parameters to save |
| `Reset` | in | BOOL | FALSE | rising edge clears an error |
| `Table` | in-out | ARRAY[1..16, 1..8] OF REAL | | the recipe table |
| `Params` | out | ARRAY[1..8] OF REAL | | the loaded recipe |
| `Loaded` | out | INT | | the recipe last loaded; 0: none |
| `Done` | out | BOOL | | TRUE for one call after a load or save |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F11.recipe.load]** A rising edge of `Load` copies row `Number` of the
   table into `Params` and sets `Loaded`.
2. **[F11.recipe.save]** A rising edge of `Save` copies `Actual` into row
   `Number`; `Params` and `Loaded` stay.
3. **[F11.recipe.range]** A number outside 1 … 16 is fault 1; nothing is
   copied.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | recipe number out of range | `Reset` |

## Not covered
