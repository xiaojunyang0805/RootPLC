# F08.ALARM · `RB_Alarm`

**Family:** F08 alarms and events · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Turns an alarm condition into an alarm an operator can see and
acknowledge, with on and off delays against nuisance alarms and the alarm
states operators know (ISA-18.2 state names, public concepts only).

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `In` | in | BOOL | | alarm condition (for analog limits: a compare, with `RB_Deadband` or hysteresis) |
| `Enable` | in | BOOL | TRUE | FALSE: out of service (shelved), state `Normal` |
| `OnDelay` / `OffDelay` | in | TIME | T#0s | the condition must hold / be gone this long |
| `Ack` | in | BOOL | FALSE | rising edge acknowledges |
| `Active` | out | BOOL | | the alarm is active |
| `Unacked` | out | BOOL | | needs acknowledging |
| `State` | out | `RB_ALARM_STATE` | | `Normal`, `ActiveUnack`, `ActiveAcked`, `ReturnedUnack` |
| `Count` | out | UDINT | | times it became active |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F08.alarm.on]** The alarm becomes active, and unacknowledged, when
   `In` has been TRUE for `OnDelay`; `Count` increases.
2. **[F08.alarm.off]** It returns when `In` has been FALSE for `OffDelay`;
   it stays unacknowledged until acknowledged.
3. **[F08.alarm.ack]** A rising edge of `Ack` acknowledges, active or
   returned.
4. **[F08.alarm.state]** `State` is `ActiveUnack`, `ActiveAcked`,
   `ReturnedUnack` or `Normal` from `Active` and `Unacked`.
5. **[F08.alarm.shelve]** `Enable` FALSE clears the alarm and keeps it
   `Normal`; when enabled again, a present condition raises it anew.
