# F01.AVERAGE · `RB_MovingAverage`

**Family:** F01 signal conditioning · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Averages the last `Window` samples (one sample per call), for example to
calm a weight or level reading.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `In` | in | REAL | | sample |
| `Window` | in | INT | 10 | samples averaged, clamped to 1 … 32 |
| `Reset` | in | BOOL | FALSE | rising edge empties the window |
| `Out` | out | REAL | | average of the samples so far (at most `Window`) |
| `Valid` | out | BOOL | | the window is full |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F01.avg.window]** `Out` is the mean of the last `Window` samples;
   until the window is full, of the samples taken so far.
2. **[F01.avg.valid]** `Valid` is TRUE once `Window` samples were taken.
3. **[F01.avg.clamp]** `Window` below 1 counts as 1, above 32 as 32.
4. **[F01.avg.reset]** A rising edge of `Reset` empties the window; the
   sample of that call is the first of the new window.
