# F09.RUNHOURS · `RB_RunHours`

**Family:** F09 supervision and diagnostics · **Level:** L1 elementary
function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Counts the run hours and starts of a device and tells when maintenance is
due, for condition-based service of motors, pumps and fans.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Running` | in | BOOL | FALSE | the device runs (for example `RB_Motor.Running`) |
| `Interval` | in | LREAL | 0 | hours between services; 0: none |
| `ServiceDone` | in | BOOL | FALSE | rising edge: a service was done |
| `Load` | in | BOOL | FALSE | rising edge: take the preset values |
| `PresetHours` / `PresetStarts` / `PresetSince` | in | LREAL / UDINT / LREAL | 0 | values to restore |
| `Hours` / `Starts` | out | LREAL / UDINT | | run hours, starts |
| `SinceService` | out | LREAL | | hours since the last service |
| `MaintenanceDue` | out | BOOL | | `SinceService` ≥ `Interval` (when set) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F09.runhours.count]** The time between two calls counts when the
   device was running at the earlier call (so the time up to the call that
   sees it stop counts too).
2. **[F09.runhours.starts]** Each rising edge of `Running` is a start.
3. **[F09.runhours.service]** `MaintenanceDue` when `Interval` > 0 and
   `SinceService` ≥ `Interval`; a rising edge of `ServiceDone` sets
   `SinceService` to 0.
4. **[F09.runhours.restore]** A rising edge of `Load` takes the preset
   values (keep the outputs in RETAIN variables and load them at start;
   the runtime retains elementary RETAIN variables, [runtime.retain]).
