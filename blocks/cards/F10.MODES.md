# F10.MODES · `RB_ModeManager`

**Family:** F10 machine modes and states · **Level:** L1 (one per machine
or unit) · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Chooses the operating mode of a machine or unit (`Off`, `Manual`, `Auto`)
from operator requests, under the conditions that allow each mode, and
feeds it to the `Mode` input of every device module of that machine. The
emergency-stop status reported by the safety system forces `Off`.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `ReqOff` / `ReqManual` / `ReqAuto` | in | BOOL | FALSE | requests, on their rising edge |
| `AutoAllowed` | in | BOOL | TRUE | conditions for Auto (homed, no fault, guards closed, ...) |
| `ManualAllowed` | in | BOOL | TRUE | conditions for Manual (e.g. key switch) |
| `EStopOk` | in | BOOL | TRUE | status from the safety system |
| `Fault` | in | BOOL | FALSE | a machine fault |
| `Mode` | out | `RB_MODE` | | the mode |
| `ModeChanged` | out | BOOL | | TRUE for one call after a change |
| `Rejected` | out | BOOL | | TRUE in the call of a request that was not allowed |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F10.modes.request]** A request acts on its rising edge; several in
   one call: Off before Manual before Auto.
2. **[F10.modes.allowed]** Manual needs `ManualAllowed`; Auto needs
   `AutoAllowed` and no `Fault`; otherwise the request is rejected.
3. **[F10.modes.fallback]** In Auto, a `Fault` or losing `AutoAllowed`
   drops the mode to Off; in Manual, losing `ManualAllowed` does. A fault
   does not end Manual (the operator may need it to clear the fault).
4. **[F10.modes.estop]** `EStopOk` FALSE forces Off and rejects requests
   for Manual or Auto; when it returns, the mode stays Off until a new
   request.

## Combines with

The `Mode` input of every F04 device module and `RB_PID`;
`RB_MachineState` for the production state; F08 alarms feeding `Fault`.

## Not covered

The emergency stop itself and any safety function (certified hardware);
setup or maintenance modes with reduced speed (planned).
