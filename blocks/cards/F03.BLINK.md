# F03.BLINK · `RB_Blink`

**Family:** F03 timing, counting, scheduling · **Level:** L1 elementary
function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

A pulse generator: on for `OnTime`, off for `OffTime`, while enabled.
Flashing lamps, horns, lubrication and blow-off pulses.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Enable` | in | BOOL | FALSE | TRUE: pulse |
| `OnTime` / `OffTime` | in | TIME | T#500ms | phase lengths |
| `Out` | out | BOOL | | the pulse |
| `Pulses` | out | UDINT | | on phases since the block started |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F03.blink.start]** Enabling starts with an on phase; disabling sets
   `Out` FALSE at once.
2. **[F03.blink.phase]** The phases alternate with exact TIME arithmetic:
   a late call does not shift the following edges.
3. **[F03.blink.count]** `Pulses` counts on phases.

## Tests

`conformance/cases/blocks/ok_rb_round5.st` (`blink_*`). Library mutation score against all block tests: 99% (1259 of 1265 library mutants, 6 Nov 2026; the six survivors are equivalent mutants in `RB_MotorReversing`, `RB_AlarmSummary`, `RB_Trips` and `RB_PID`).

## Combines with

`RB_AlarmSummary` (its own flashing lamp), F04 device modules (pulsed
commands), `RB_Drum` for longer patterns.

## Not covered

Phases shorter than the PLC cycle (one toggle per call), synchronising
several blinkers (use one and fan out `Out`).
