# F10.STATE · `RB_MachineState`

**Family:** F10 machine modes and states · **Level:** L1 (one per machine)
· **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Gives a machine a production state model that operators, MES and
packaging lines recognise: a subset of the PackML state model (public
state names only). Commands move it between states; the acting states end
when the machine's logic (typically `RB_StepChain`s) reports done.

## Interface

| Name | Direction | Type | Meaning |
|---|---|---|---|
| `Reset`, `Start`, `Stop`, `Hold`, `Unhold`, `Abort`, `Clear` | in | BOOL | commands, on their rising edge |
| `ResetDone`, `StartDone`, `StopDone` | in | BOOL | machine logic: the acting state finished |
| `State` | out | `RB_MACHINE_STATE` | `Stopped`, `Resetting`, `Idle`, `Starting`, `Execute`, `Stopping`, `Held`, `Aborted` |
| `Producing` | out | BOOL | `State = Execute` |
| `Rejected` | out | BOOL | TRUE in the call of a command not valid in the state |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F10.state.cycle]** Stopped –Reset→ Resetting –ResetDone→ Idle
   –Start→ Starting –StartDone→ Execute; Execute –Hold→ Held –Unhold→
   Execute.
2. **[F10.state.stop]** `Stop` from Idle, Starting, Execute or Held →
   Stopping –StopDone→ Stopped.
3. **[F10.state.abort]** `Abort` from any state but Aborted → Aborted;
   `Clear` → Stopped.
4. **[F10.state.priority]** Several commands in one call: Abort, Clear,
   Stop, Hold, Unhold, Start, Reset, in this order.
5. **[F10.state.done]** A done input acts only in its own acting state.
6. **[F10.state.rejected]** A command not valid in the state changes
   nothing and sets `Rejected` for that call.

## Combines with

`RB_ModeManager` (Execute normally needs Auto), `RB_StepChain` for the
acting states and production, `RB_Counter` and F09 OEE counters on
`Producing`.

## Not covered

The full PackML model (Suspended, Completing/Complete, Holding,
Unholding, Clearing as acting state, Aborting), PackTags (planned with
F11).
