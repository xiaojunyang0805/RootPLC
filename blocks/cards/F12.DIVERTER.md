# F12.DIVERTER · `RB_Diverter`

**Family:** F12 material handling · **Level:** L2 device module · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Sorts parts on a conveyor: a gate sends each part straight on or into a
branch, by a destination read when the part arrives, and holds the feeding
conveyor while the gate is not yet in position.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `PartAtGate` | in | BOOL | FALSE | eye in front of the gate |
| `Divert` | in | BOOL | FALSE | destination of the arriving part: TRUE branch |
| `FbDiverted` / `FbStraight` | in | BOOL | FALSE | gate position switches |
| `Feedback` | in | BOOL | TRUE | FALSE when no position switches are fitted |
| `MoveTime` | in | TIME | T#2s | the gate must be in position within this |
| `PassTime` | in | TIME | T#1s | the gate holds after the part left the eye |
| `Reset` | in | BOOL | FALSE | rising edge clears a fault |
| `Gate` | out | BOOL | | TRUE: gate to the branch |
| `HoldPart` | out | BOOL | | stop the feeding conveyor |
| `ToBranch` / `ToStraight` | out | UDINT | | parts sorted |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F12.diverter.route]** `Divert` is read on the rising edge of
   `PartAtGate`; changing it while the part passes has no effect.
2. **[F12.diverter.hold]** While a part waits and the gate is not in its
   position (both switches checked), `HoldPart` is TRUE.
3. **[F12.diverter.pass]** When the part leaves the eye it is counted to
   its destination; the gate holds for `PassTime`, then returns straight. A
   part arriving meanwhile takes the gate over at once.
4. **[F12.diverter.timeout]** The gate not in position for `MoveTime` is
   fault 1: gate de-energised (straight) and `HoldPart` TRUE (safe state).
   A rising edge of `Reset` clears it and gives the gate a new `MoveTime`.
5. **[F12.diverter.no-feedback]** With `Feedback` FALSE the gate counts as
   in position at once.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | the gate did not reach its position within `MoveTime` | `Reset` |

## Combines with

`RB_ConveyorZone` (`HoldPart` into the zone's stop), `RB_Fifo` (the
destination travels with the part's ID), barcode readers, `RB_Cylinder`
for a pusher-type diverter.

## Not covered

Merges, more than two destinations (chain diverters), tracking by encoder
position.
