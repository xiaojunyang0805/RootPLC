# F04.GROUP · `RB_DutyStandby`

**Family:** F04 device modules · **Level:** L3 equipment function (a group
of devices) · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Runs a group of up to four identical units (pumps, fans, compressors) as
duty and standby: as many as the demand asks, the ones with the fewest run
hours first, one start at a time, and a standby unit takes over at once
when a running one fails.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Demand` | in | INT | 0 | units wanted, limited to 0 … `Used` |
| `Available` | in | ARRAY[1..4] OF BOOL | | unit healthy and in Auto |
| `Hours` | in | ARRAY[1..4] OF REAL | | run hours (`RB_RunHours`) |
| `Used` | in | INT | 4 | units fitted, limited to 1 … 4 |
| `StageDelay` | in | TIME | T#0s | minimum time between two starts |
| `Run` | out | ARRAY[1..4] OF BOOL | | `AutoRun` of each unit |
| `Running` | out | INT | | units commanded to run |
| `Shortfall` | out | BOOL | | fewer units available than demanded |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F04.group.select]** When fewer units run than demanded, the available
   idle unit with the fewest hours starts (the lowest number on equal
   hours). Running units are not swapped when hours change.
2. **[F04.group.stage]** A start needs `StageDelay` since the previous
   start, except the first unit of a group at rest and the replacement of
   a failed unit.
3. **[F04.group.failover]** A running unit that becomes unavailable (or is
   above `Used`) stops at once and is replaced in the same call.
4. **[F04.group.stop]** When more units run than demanded, the one with the
   most hours stops (the lowest number on equal hours).
5. **[F04.group.shortfall]** `Shortfall` is TRUE while fewer units are
   available than demanded.

## Combines with

`RB_Pump`, `RB_Motor`, `RB_Drive` (their `Error` and mode into
`Available`, `Run` into `AutoRun`), `RB_RunHours` (`Hours`), F06 control
or `RB_AnalogLimits` deciding `Demand`, F08 alarms on `Shortfall`.

## Not covered

Rotation on a schedule while running (change of duty without demand
change), more than four units, units of different sizes.
