# F08.EVENTS · `RB_EventLog`

**Family:** F08 alarms and events · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Keeps the last 32 events with their time stamps: alarm numbers, machine
states, operator actions, first-out codes. A short history in the
controller for the HMI and for diagnosis after a stop.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Code` | in | DINT | 0 | the event code |
| `Log` | in | BOOL | FALSE | rising edge: log `Code` |
| `OnChange` | in | BOOL | FALSE | TRUE: log every change to a non-zero `Code` |
| `Now` | in | DT | | date and time from the controller's clock |
| `Clear` | in | BOOL | FALSE | rising edge: empty the log |
| `Codes` / `Stamps` | out | ARRAY[1..32] OF DINT / DT | | the ring |
| `Newest` | out | INT | | index of the newest event; 0: none |
| `Count` | out | INT | | events stored, up to 32 |
| `Total` | out | UDINT | | events logged since the block started |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F08.events.log]** A rising edge of `Log` stores `Code` with `Now`;
   with `OnChange`, so does every change of `Code` to a non-zero value.
2. **[F08.events.ring]** Events go into a ring of 32; the oldest is
   overwritten; `Newest` points to the latest.
3. **[F08.events.clear]** A rising edge of `Clear` empties the log;
   `Total` keeps counting.

## Combines with

`RB_Trips` (`FirstOut` with `OnChange`), `RB_MachineState` (the state as a
code), `RB_AlarmSummary`, the HMI reading the arrays.

## Not covered

Event texts (an HMI job), storage across power loss, more than one event
per call.
