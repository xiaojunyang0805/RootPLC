# F11.TRANSFER · `RB_Transfer`

**Family:** F11 data handling and communication · **Level:** L1 (between
two stations) · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Hands a part from this station to the next with a handshake: when this
station has a part and the next is ready, `Release` moves it (conveyor,
gate, gripper) until the next station confirms that it arrived, with a
timeout.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `PartReady` | in | BOOL | FALSE | this station has a part to hand on |
| `ReceiverReady` | in | BOOL | FALSE | the next station can take it |
| `Arrived` | in | BOOL | FALSE | the next station has the part |
| `Timeout` | in | TIME | T#10s | arrival must follow within this |
| `Reset` | in | BOOL | FALSE | rising edge clears a timeout |
| `Release` / `Busy` | out | BOOL | | moving the part |
| `Done` | out | BOOL | | TRUE for one call when a part arrived |
| `Count` | out | UDINT | | parts handed on |
| `Error` / `ErrorID` | out | BOOL / UDINT | | timeout ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F11.transfer.start]** A transfer starts when `PartReady` and
   `ReceiverReady` are both TRUE and there is no error.
2. **[F11.transfer.finish]** Once started it continues (even if the
   receiver drops its ready signal) until `Arrived`, which gives `Done` for
   one call and counts the part.
3. **[F11.transfer.timeout]** No arrival within `Timeout` is fault 1: the
   transfer stops and no new one starts until `Reset`.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | the part did not arrive within `Timeout` | `Reset` |

## Combines with

F05 step chains on both sides, `RB_ConveyorZone`, `RB_Fifo` (pass the
part's data along), F08 alarms on `Error`.

## Not covered

The receiver side as a block (a step that sets `ReceiverReady` and senses
`Arrived`), data exchange over a fieldbus.
