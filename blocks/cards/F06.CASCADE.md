# F06.CASCADE · `RB_Cascade`

**Family:** F06 closed-loop control · **Level:** L3 equipment function
(two loops) · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Cascade control: an outer (primary) loop, e.g. a tank temperature, sets
the set point of an inner (secondary) loop, e.g. the jacket temperature or
a steam flow, whose output drives the actuator. The inner loop rejects
disturbances before they reach the primary value. Built from two `RB_PID`.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Mode` | in | `RB_MODE` | `Off` | `Off`, `Manual` or `Auto` ([blocks.mode]) |
| `Cascade` | in | BOOL | TRUE | in Auto: FALSE runs the inner loop alone on `InnerSP` |
| `SP` / `PV` | in | REAL | 0 | primary set point and value |
| `InnerSP` / `InnerPV` | in | REAL | 0 | inner set point without cascade, secondary value |
| `KpOuter`, `TiOuter`, `KpInner`, `TiInner` | in | REAL / TIME | 1.0 / T#0s | tuning (P or PI) |
| `InnerSPMin` / `InnerSPMax` | in | REAL | 0 / 100 | range of the inner set point (the outer output) |
| `OutMin` / `OutMax` | in | REAL | 0 / 100 | actuator range |
| `ManValue` | in | REAL | 0 | output in Manual |
| `Reset` | in | BOOL | FALSE | rising edge clears a fault |
| `Out` | out | REAL | | actuator command |
| `InnerSPUsed` | out | REAL | | the inner set point in use |
| `InCascade` | out | BOOL | | Auto with `Cascade` |
| `Saturated` | out | BOOL | | the inner loop is at an output limit |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F06.cascade.modes]** Auto with `Cascade`: the outer output (limited
   to the inner set-point range) is the inner set point. Auto without
   `Cascade`: the inner loop runs on `InnerSP`. Manual: `Out` =
   `ManValue`. Off: `Out` = `OutMin`.
2. **[F06.cascade.tracking]** In Manual and Off the inner set point tracks
   `InnerPV`; whenever the outer loop does not drive the inner set point,
   its output tracks `InnerPV`. Switching to Auto or to cascade is
   therefore bumpless.
3. **[F06.cascade.faults]** A fault of the inner loop (ErrorID as
   F06.PID) or of the outer loop (10 + its ErrorID: 11 inner set-point
   range empty) gives `Out` = `OutMin` (safe state) until `Reset`.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | `OutMin` ≥ `OutMax` | `Reset` after correcting |
| 11 | `InnerSPMin` ≥ `InnerSPMax` | `Reset` after correcting |

## Combines with

`RB_Scale` and `RB_FilterPT1` for both values, `RB_ValveAnalog` or
`RB_Drive` on `Out`, `RB_SplitRange` after the inner loop, `RB_ModeManager`.

## Not covered

Derivative action (use `RB_PID` directly), stopping the outer integral
while the inner loop is saturated (the inner set-point range limits it),
feed-forward.
