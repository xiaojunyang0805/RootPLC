# F08.LIMITS · `RB_AnalogLimits`

**Family:** F08 alarms and events · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Checks an analog value against four limits (high-high, high, low,
low-low) with hysteresis, so a value hovering at a limit does not make the
alarm chatter. Its outputs feed `RB_Alarm` blocks (delays,
acknowledgement) or interlocks.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Value` | in | REAL | 0 | the measurement |
| `HH` / `H` / `L` / `LL` | in | REAL | 95 / 85 / 15 / 5 | limits |
| `Hysteresis` | in | REAL | 1.0 | clearing distance |
| `EnHH` / `EnH` / `EnL` / `EnLL` | in | BOOL | TRUE | FALSE: limit not used |
| `HiHi` / `Hi` / `Lo` / `LoLo` | out | BOOL | | limit active |
| `Error` / `ErrorID` | out | BOOL / UDINT | | settings fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F08.limits.high]** `Hi` becomes TRUE when `Value` > `H` and stays
   TRUE while `Value` ≥ `H` − `Hysteresis`; `HiHi` likewise with `HH`.
2. **[F08.limits.low]** `Lo` becomes TRUE when `Value` < `L` and stays TRUE
   while `Value` ≤ `L` + `Hysteresis`; `LoLo` likewise with `LL`.
3. **[F08.limits.enable]** A disabled limit's output is FALSE.
4. **[F08.limits.settings]** `LL` > `L`, `L` ≥ `H`, `H` > `HH` or a
   negative `Hysteresis` is fault 1; all four outputs are FALSE while the
   settings are wrong.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | limits not in order, or negative hysteresis | correct settings |

## Combines with

`RB_Scale` (the value), `RB_Alarm` ×4 (delays and acknowledgement),
`RB_AlarmSummary`, F04 `Interlock` inputs (high-high stops a pump).

## Not covered

Rate-of-change alarms, deviation alarms against a set point, limits in
percent of range.
