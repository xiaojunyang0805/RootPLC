# F06.PWM · `RB_PWM`

**Family:** F06 closed-loop control · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Time-proportioning output: turns a controller output of 0 … 100 % into an
on/off signal with a fixed period, for heaters switched by contactors or
solid-state relays, and for dosing pumps.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `In` | in | REAL | 0 | duty, %, limited to 0 … 100 |
| `Period` | in | TIME | T#2s | cycle of the output |
| `MinPulse` | in | TIME | T#0s | shortest on or off pulse |
| `Enable` | in | BOOL | TRUE | FALSE: off |
| `Out` | out | BOOL | | the output |
| `OnTime` | out | TIME | | on time in the current period |
| `Error` / `ErrorID` | out | BOOL / UDINT | | settings fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F06.pwm.period]** Each period begins on, for `OnTime` = `Period` ×
   `In` / 100, taken at the start of the period (a change of `In` waits for
   the next period); periods follow each other exactly.
2. **[F06.pwm.min-pulse]** An on time shorter than `MinPulse` becomes 0;
   an off time shorter than `MinPulse` becomes 0 (on for the whole period).
3. **[F06.pwm.enable]** Disabling sets `Out` FALSE; enabling starts a new
   period.
4. **[F06.pwm.settings]** `Period` T#0s is fault 1: `Out` FALSE.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | `Period` is T#0s | a valid `Period` |

## Not covered

heater groups.
