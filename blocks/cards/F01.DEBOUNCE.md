# F01.DEBOUNCE · `RB_Debounce`

**Family:** F01 signal conditioning · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Filters a bouncing or flickering contact: the output switches on only
after the input has been on for `OnDelay`, and off only after it has been
off for `OffDelay`.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `In` | in | BOOL | | contact |
| `OnDelay` / `OffDelay` | in | TIME | T#20ms | stable time needed to switch on / off |
| `Out` | out | BOOL | | debounced contact |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F01.debounce.on]** `Out` becomes TRUE when `In` has been TRUE for
   `OnDelay` without interruption.
2. **[F01.debounce.off]** `Out` becomes FALSE when `In` has been FALSE for
   `OffDelay` without interruption.
3. **[F01.debounce.short]** Shorter pulses or drops leave `Out` unchanged.
