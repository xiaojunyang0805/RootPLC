# F01.PEAK · `RB_PeakHold`

**Family:** F01 signal conditioning · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Holds the minimum, maximum and average of a value since the last reset:
drag pointers on a test bench, peak loads and pressures, the range of a
shift or a batch.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Value` | in | REAL | 0 | the value |
| `Enable` | in | BOOL | TRUE | FALSE: pause |
| `Reset` | in | BOOL | FALSE | rising edge: start again |
| `Minimum` / `Maximum` / `Average` | out | REAL | | since the reset; 0 before the first sample |
| `Samples` | out | UDINT | | values taken |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F01.peak.sample]** Each call with `Enable` takes `Value`: the first
   sets minimum and maximum, later ones widen them; the average covers all
   samples.
2. **[F01.peak.reset]** A rising edge of `Reset` sets everything to 0; the
   value in the same call is the first new sample.

## Combines with

`RB_Scale` (the value), `RB_Schedule` or a batch start on `Reset`,
`RB_DataLog` (the trend behind the peaks).

## Not covered

Time stamps of the peaks (combine with `RB_EventLog`), a moving window
(use `RB_MovingAverage` or `RB_DataLog`).
