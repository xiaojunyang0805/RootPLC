# F09.TOTAL · `RB_Totalizer`

**Family:** F09 supervision and diagnostics · **Level:** L1 elementary
function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Integrates a rate over time into a total: flow into volume, power into
energy (kW into kWh, the usual energy meter), with a low-flow cut-off and
a batch total with a preset for dosing a quantity.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Rate` | in | REAL | 0 | in units per `TimeBase` |
| `TimeBase` | in | TIME | T#1h | m3/h, kW → kWh: T#1h; l/min: T#1m |
| `LowCut` | in | REAL | 0 | rates at or below this count as 0 |
| `Hold` | in | BOOL | FALSE | TRUE: do not count |
| `StartBatch` | in | BOOL | FALSE | rising edge: batch total to 0 |
| `Preset` | in | LREAL | 0 | batch quantity; 0: none |
| `Reset` | in | BOOL | FALSE | rising edge: total to 0 |
| `Total` / `BatchTotal` | out | LREAL | | totals |
| `BatchDone` | out | BOOL | | `BatchTotal` ≥ `Preset` (> 0) |
| `Counting` | out | BOOL | | the rate is being counted |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F09.total.integrate]** Each call adds `Rate` × (time since the
   previous call) / `TimeBase` to both totals, unless `Hold`, `Rate` ≤
   `LowCut` or `TimeBase` is T#0s.
2. **[F09.total.batch]** A rising edge of `StartBatch` sets `BatchTotal` to
   0; `BatchDone` while `Preset` > 0 and `BatchTotal` ≥ `Preset`.
3. **[F09.total.reset]** A rising edge of `Reset` sets `Total` to 0.
4. **[F09.total.precision]** Totals are LREAL, so long-running totals keep
   their resolution.

## Combines with

`RB_Scale` and `RB_FilterPT1` for the rate, `RB_ValveOnOff` closing on
`BatchDone` (dosing), `RB_Schedule` or a shift change on `Reset`, Modbus
for SCADA reporting.

## Not covered

Retained totals across power loss (runtime v0 retains elementary RETAIN
variables: copy `Total` into one), pulse inputs from meters (count with
`RB_Counter`), in-flight compensation for dosing.
