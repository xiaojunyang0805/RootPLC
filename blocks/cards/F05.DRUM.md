# F05.DRUM · `RB_Drum`

**Family:** F05 sequencing · **Level:** L1 elementary function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

A drum (cam) sequencer: up to 16 steps, each setting a pattern of 16
outputs and lasting a time or waiting for an event. Simple fixed cycles:
washing and cleaning programs, lubrication cycles, signal sequences,
test rigs.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Run` | in | BOOL | FALSE | TRUE: step times run |
| `Next` | in | BOOL | FALSE | rising edge: next step now |
| `Reset` | in | BOOL | FALSE | rising edge: back to step 1 |
| `Patterns` | in | ARRAY[1..16] OF WORD | | outputs of each step (bit 0 … 15) |
| `Times` | in | ARRAY[1..16] OF TIME | | time of each step; T#0s waits for `Next` |
| `Count` | in | INT | 16 | steps used, 1 … 16 |
| `Cyclic` | in | BOOL | TRUE | after the last step: step 1 again |
| `StepNo` | out | INT | | current step |
| `Out` | out | WORD | | the current step's pattern |
| `StepTime` | out | TIME | | time spent in the step (while `Run`) |
| `Done` | out | BOOL | | not cyclic: the last step ended |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F05.drum.start]** The drum starts at step 1 (also after `Reset`, or
   when `Count` falls below the current step).
2. **[F05.drum.time]** With `Run`, a step with a time > T#0s ends when its
   time has run (paused while `Run` is FALSE; exact TIME arithmetic).
3. **[F05.drum.next]** A rising edge of `Next` ends the step at once.
4. **[F05.drum.end]** After step `Count`: step 1 again with `Cyclic`,
   otherwise the drum stays on the last step with `Done` until `Reset`.
5. **[F05.drum.count]** `Count` outside 1 … 16 is fault 1: `Out` 0,
   `StepNo` 0.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | `Count` outside 1 … 16 | a valid `Count` |

## Combines with

F04 device modules (pattern bits as automatic commands), `RB_ModeManager`
(`Run` in Auto), `RB_StepChain` for sequences with conditions and
branches.

## Not covered

Conditions per step other than `Next`, more than 16 outputs (two drums
with the same inputs), counted (event) steps.
