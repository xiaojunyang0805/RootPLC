# F01.VOTE · `RB_Vote2oo3`

**Family:** F01 signal conditioning · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

One reliable measurement from three redundant transmitters (critical
pressures, levels, temperatures): the median of the healthy ones, with a
flag for any transmitter that drifts away from the result.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `A` / `B` / `C` | in | REAL | 0 | the three measurements |
| `OkA` / `OkB` / `OkC` | in | BOOL | TRUE | signal healthy (e.g. NOT `RB_Scale.Error`) |
| `MaxDev` | in | REAL | 2.0 | allowed difference from the result |
| `Value` | out | REAL | | the voted measurement |
| `Healthy` | out | INT | | transmitters used |
| `DevA` / `DevB` / `DevC` | out | BOOL | | the transmitter differs by more than `MaxDev` |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F01.vote.value]** Three healthy: the median; two: their average;
   one: that one.
2. **[F01.vote.deviation]** A healthy transmitter more than `MaxDev` from
   `Value` is flagged; exactly `MaxDev` is not.
3. **[F01.vote.none]** No healthy transmitter is fault 1: `Value` keeps its
   last good value, no deviation flags.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | no healthy transmitter | a healthy transmitter |

## Tests

## Combines with

`RB_Scale` ×3 (`Error` into `OkX`), `RB_AnalogLimits` (trips on the voted
value), `RB_Alarm` on the deviation flags.

## Not covered

2oo3 voting of digital trips, excluding a deviating transmitter
automatically, safety-rated voting (a safety function on certified
hardware).
