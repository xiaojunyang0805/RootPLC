# F03.CYCLETIME · `RB_CycleTime`

**Family:** F03 timing · **Level:** L1 elementary function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Gives the time since the previous call, in seconds, for blocks that
integrate or limit rates (filters, ramps, totalisers). It measures with a
standard timer, so it runs on the PLC clock in tests, simulation and the
runtime alike ([blocks.testable]).

## Interface

| Name | Direction | Type | Meaning |
|---|---|---|---|
| `Seconds` | out | LREAL | seconds since the previous call; 0 in the first call |
| `Elapsed` | out | TIME | the same as a TIME, exact (for adding up times without rounding) |
| `FirstCall` | out | BOOL | TRUE in the first call |

## Behaviour rules

1. **[F03.cycletime.first]** The first call gives `Seconds` 0 and
   `FirstCall` TRUE.
2. **[F03.cycletime.seconds]** Every later call gives the time since the
   previous call, in `Seconds` and exactly in `Elapsed`; two calls at the
   same instant give 0.
3. **[F03.cycletime.long-run]** The internal timer restarts once a day
   without losing time.

## Not covered

Wall-clock time and dates (use the system's date functions).
