# F06.RATIO · `RB_Ratio`

**Family:** F06 closed-loop control · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Makes the set point of one flow proportional to another (the wild flow):
blending two components, air to fuel on a burner, dosing a chemical in
proportion to a water flow.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Wild` | in | REAL | 0 | the flow that is not controlled |
| `Ratio` | in | REAL | 1.0 | |
| `Bias` | in | REAL | 0 | |
| `SPMin` / `SPMax` | in | REAL | 0 / 100 | set point limits |
| `SP` | out | REAL | | `Ratio` × `Wild` + `Bias`, limited |
| `Limited` | out | BOOL | | `SP` is at a limit |
| `Error` / `ErrorID` | out | BOOL / UDINT | | settings fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F06.ratio.sp]** `SP` = `Ratio` × `Wild` + `Bias`, limited to
   `SPMin` … `SPMax`; `Limited` is TRUE when the limit cuts in.
2. **[F06.ratio.settings]** `SPMin` > `SPMax` is fault 1; `SP` is `SPMin`
   and `Limited` TRUE while the settings are wrong.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | `SPMin` > `SPMax` | correct settings |

## Combines with

`RB_PID` (`SP` as its set point), `RB_Scale` and `RB_FilterPT1` for the
wild flow, `RB_ValveAnalog`.

## Not covered

Cross-limiting of air and fuel (lead-lag on load changes), ratio from a
recipe (wire `RB_RecipeTable`).
