# F01.FILTER.PT1 · `RB_FilterPT1`

**Family:** F01 signal conditioning · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Smooths a noisy measurement with a first-order low-pass filter (PT1) of
time constant `T`, independent of the PLC cycle time.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `In` | in | REAL | | measurement |
| `T` | in | TIME | T#1s | time constant; T#0s passes `In` through |
| `Track` | in | BOOL | FALSE | TRUE: `Out` follows `In` directly |
| `Out` | out | REAL | | filtered value |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F01.pt1.start]** In the first call `Out` = `In`.
2. **[F01.pt1.filter]** Afterwards `Out += (In - Out) · dt / (T + dt)`,
   with dt the time since the previous call: after one time constant a step
   has risen to about 63%, after five to more than 99%.
3. **[F01.pt1.pass]** With `Track` TRUE, or `T` = T#0s, `Out` = `In`.
