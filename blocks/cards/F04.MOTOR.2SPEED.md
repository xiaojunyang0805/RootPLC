# F04.MOTOR.2SPEED · `RB_MotorTwoSpeed`

**Family:** F04 device modules · **Level:** L2 device module · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Runs a two-speed motor (two windings or Dahlander) with a slow and a fast
contactor: fans, conveyors, mixers. A speed change goes through a short
pause with both contactors off. The run logic (mode, interlock,
permissive, restart delay, feedback, overload) is `RB_Motor`.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Mode`, `AutoRun`, `ManRun`, `Interlock`, `Permissive`, `Overload`, `Feedback`, `FeedbackTime`, `RestartDelay`, `Reset` | in | | | as `RB_Motor` (F04.MOTOR.DOL) |
| `AutoFast` / `ManFast` | in | BOOL | FALSE | requested speed: TRUE fast |
| `FbSlow` / `FbFast` | in | BOOL | FALSE | contactor auxiliary contacts |
| `Changeover` | in | TIME | T#500ms | both off between speeds |
| `Slow` / `Fast` | out | BOOL | | contactor outputs |
| `Running` | out | BOOL | | running, from either feedback |
| `AtFast` | out | BOOL | | running fast |
| `Error` / `ErrorID` / `Status` | out | | | as `RB_Motor` |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F04.2speed.start]** A start switches on the contactor of the speed
   requested at that moment.
2. **[F04.2speed.change]** A change of the requested speed while running
   switches both contactors off for `Changeover`, then on at the speed
   requested at the end of the pause; slow and fast are never on together.
3. **[F04.2speed.motor]** Mode, interlock, permissive, restart delay,
   feedback supervision (either contactor's contact) and faults follow
   F04.MOTOR.DOL; `FeedbackTime` must be longer than `Changeover`. Safe
   state: both contactors de-energised.

## Faults

As F04.MOTOR.DOL: 1 no running feedback, 2 contactor stuck, 3 overload.

## Combines with

F06 on/off control choosing the speed (`RB_OnOff` on temperature for a
fan), F09 run hours, F08 alarms on `Error`.

## Not covered

A required stop before changing speed, slowing down by braking, pole
changers with more than two speeds.
