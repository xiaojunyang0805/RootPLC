# F04.DRIVE · `RB_Drive`

**Family:** F04 device modules · **Level:** L2 device module ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Commands a variable-speed drive (VFD) and supervises its status: run,
direction and a clamped speed set point out; ready, running, fault and
actual speed in. The application maps these to the drive's control and
status word (fieldbus) or to its digital and analog I/O, so the block
works with any drive brand. The drive does its own ramping.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Mode` | in | `RB_MODE` | `Off` | `Off`, `Manual` or `Auto` ([blocks.mode]) |
| `AutoRun` / `AutoSpeed` / `AutoReverse` | in | BOOL / REAL / BOOL | FALSE / 0 / FALSE | automatic command, set point, direction |
| `ManRun` / `ManSpeed` / `ManReverse` | in | BOOL / REAL / BOOL | FALSE / 0 / FALSE | manual command, set point, direction |
| `Interlock` | in | BOOL | FALSE | TRUE stops now, in every mode |
| `Permissive` | in | BOOL | TRUE | FALSE: do not start |
| `DriveReady` / `DriveRunning` / `DriveFault` | in | BOOL | FALSE | drive status |
| `ActualSpeed` | in | REAL | 0 | actual speed, same unit as the set point |
| `SpeedMin` / `SpeedMax` | in | REAL | 0 / 100 | set point limits |
| `SpeedTolerance` | in | REAL | 0 | allowed deviation; 0: no speed supervision |
| `FeedbackTime` | in | TIME | T#5s | supervision time (run feedback, speed) |
| `Reset` | in | BOOL | FALSE | rising edge clears a fault |
| `Run` / `Reverse` | out | BOOL | | run command, direction |
| `SpeedSetpoint` | out | REAL | | clamped set point; 0 when not running |
| `ResetDrive` | out | BOOL | | one-call pulse on `Reset`, for the drive's own fault reset |
| `Running` | out | BOOL | | from `DriveRunning` |
| `AtSpeed` | out | BOOL | | running and within `SpeedTolerance` (running, when no tolerance is set) |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |
| `Status` | out | `RB_DEVICE_STATUS` | | for the HMI ([blocks.status]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F04.drive.mode]** In `Auto` the automatic command, set point and
   direction apply, in `Manual` the manual ones, in `Off` the drive is
   stopped.
2. **[F04.drive.start]** A start needs `Permissive` and `DriveReady`;
   neither stops a running drive.
3. **[F04.drive.interlock]** `Interlock` TRUE stops the drive at once, in
   every mode.
4. **[F04.drive.setpoint]** While running, `SpeedSetpoint` is the set point
   clamped to `SpeedMin` … `SpeedMax` and `Reverse` the direction; when not
   running both are 0 / FALSE.
5. **[F04.drive.fault]** `DriveFault` TRUE is fault 3 at once.
6. **[F04.drive.run-feedback]** Run commanded, `DriveRunning` FALSE for
   `FeedbackTime`: fault 1; `DriveRunning` TRUE without a command for
   `FeedbackTime`: fault 2.
7. **[F04.drive.speed]** With `SpeedTolerance` > 0, running and the actual
   speed off the set point by more than the tolerance for `FeedbackTime`:
   fault 4. `AtSpeed` is FALSE while off by more than the tolerance.
8. **[F04.drive.reset]** A fault latches and stops the drive (safe state:
   `Run` FALSE, set point 0). A rising edge of `Reset` clears it and gives
   `ResetDrive` for one call, so the drive's own fault can be reset too.
9. **[F04.drive.status]** `Status.Starts` counts starts.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | no running feedback within `FeedbackTime` after a start | `Reset` |
| 2 | running without a command | `Reset` |
| 3 | the drive reports a fault | `Reset` (with `ResetDrive` to the drive) |
| 4 | speed deviation beyond `SpeedTolerance` | `Reset` |

## Combines with

F06 control loops (speed as the manipulated variable), F12 conveyors and
pump stations, F01 scaling of the actual speed, F08 alarms, F10 mode
managers. Fieldbus mapping (CiA 402 or vendor profiles) belongs to the
application or to the planned drive-profile adapters.

## Not covered

Ramps in the PLC (the drive ramps), torque and position modes (see
RootMotion for positioning), the drive's parameter set, safe torque off (a
safety function).
