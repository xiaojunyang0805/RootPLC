# F02.STARTSTOP · `RB_StartStop`

**Family:** F02 discrete logic and interlocks · **Level:** L1 elementary
function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

The classic start/stop latch of a push-button station: start on a press,
stop dominant, with a normally closed stop input so a broken wire also
stops.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Start` | in | BOOL | FALSE | rising edge starts |
| `StopOk` | in | BOOL | TRUE | FALSE (stop pressed or wire broken) stops |
| `Permissive` | in | BOOL | TRUE | needed to start, not to stay on |
| `Interlock` | in | BOOL | FALSE | TRUE stops ([blocks.interlock]) |
| `Out` | out | BOOL | | latched output |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F02.startstop.stop-wins]** `StopOk` FALSE or `Interlock` TRUE sets
   `Out` FALSE, also when start is pressed at the same time.
2. **[F02.startstop.start]** A rising edge of `Start` with `Permissive`
   sets `Out`; a start held while stop was pressed does not start when stop
   is released.
3. **[F02.startstop.permissive]** Losing `Permissive` does not reset `Out`.
