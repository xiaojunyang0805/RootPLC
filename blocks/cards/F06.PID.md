# F06.PID · `RB_PID`

**Family:** F06 closed-loop control · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Holds a process value (temperature, pressure, level, flow) at a set point
by computing an output (valve position, drive speed, heater power) with
proportional, integral and derivative action, without integral windup and
without bumps when switching between manual and automatic.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Mode` | in | `RB_MODE` | `Off` | `Off` (Out = OutMin), `Manual` (Out = ManValue), `Auto` (PID) |
| `SP` / `PV` | in | REAL | | set point / process value |
| `Kp` | in | REAL | 1.0 | proportional gain |
| `Ti` | in | TIME | T#0s | integral time; T#0s: no integral |
| `Td` | in | TIME | T#0s | derivative time; T#0s: no derivative |
| `OutMin` / `OutMax` | in | REAL | 0 / 100 | output range |
| `ManValue` | in | REAL | 0 | output in `Manual` (clamped to the range) |
| `Direct` | in | BOOL | FALSE | FALSE: error = SP − PV (heating); TRUE: PV − SP (cooling) |
| `Reset` | in | BOOL | FALSE | rising edge clears a fault |
| `Out` | out | REAL | | output |
| `Saturated` | out | BOOL | | `Auto` and the output at a limit |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F06.pid.law]** In `Auto`: `Out = P + I + D`, clamped to the range,
   with `P = Kp · e`, `I` the integral of `Kp · e / Ti` over time, and
   `D = −Kp · Td · dPV/dt` (sign reversed for `Direct`), e the error.
2. **[F06.pid.d-on-pv]** The derivative acts on the process value, so a
   set-point step changes the output only through P and I.
3. **[F06.pid.anti-windup]** Conditional integration: the integral does
   not change in a call in which the output is at a limit and integrating
   would push it further into that limit. The integral never grows to
   cancel the proportional term, so after a long saturation a small error of
   the other sign gives a small output (no jump to the opposite limit), and
   the output leaves a limit in the same call in which the error changes
   sign. (Found by R2, 6 Nov 2026: the earlier bound of the integral by
   `OutMin − P … OutMax − P` let it absorb P while saturated.)
4. **[F06.pid.bumpless]** In `Manual` and `Off` the integral tracks the
   output, so switching to `Auto` continues from the last output.
5. **[F06.pid.timing]** The block measures the time between calls itself
   (`RB_CycleTime`); two calls at the same instant add no integral or
   derivative.
6. **[F06.pid.fault]** `OutMin ≥ OutMax` is fault 1; `Out` = `OutMin`
   (safe state) until a rising edge of `Reset` with a valid range.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | invalid output range (`OutMin ≥ OutMax`) | `Reset` after correcting it |

## Combines with

`RB_Scale` and `RB_FilterPT1` on `PV`, `RB_Ramp` on `SP`, `RB_Drive` or an
analog valve on `Out`, F10 mode managers, F08 alarms on deviation.

## Not covered

Derivative filtering, gain scheduling, cascade control
(`RB_Cascade`; ratio set points: `RB_Ratio`), auto-tuning; split range is `RB_SplitRange`.
