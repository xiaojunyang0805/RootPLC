# F04.MOTOR.STARDELTA · `RB_MotorStarDelta`

**Family:** F04 device modules · **Level:** L2 device module · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Starts a motor star-delta with three contactors: main and star for the
start, then after `StarTime` star off, a short gap, delta on. The main
contactor logic (mode, interlock, permissive, restart delay, feedback,
overload) is `RB_Motor`.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Mode`, `AutoRun`, `ManRun`, `Interlock`, `Permissive`, `FbRunning`, `Overload`, `Feedback`, `FeedbackTime`, `RestartDelay`, `Reset` | in | | | as `RB_Motor` (F04.MOTOR.DOL); `FbRunning` is the main contactor's auxiliary contact |

| `Status` | out | `RB_DEVICE_STATUS` | | as `RB_Motor` |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F04.stardelta.start]** When the main contactor is switched on, star
   is on with it for `StarTime`.
2. **[F04.stardelta.changeover]** Then star goes off, and delta comes on
   after `Changeover`; star and delta are never on together.
3. **[F04.stardelta.stop]** When the main contactor drops (stop, interlock,
   fault) all three drop; the next start begins in star again.
4. **[F04.stardelta.motor]** Mode, interlock, permissive, restart delay,
   feedback supervision and faults follow F04.MOTOR.DOL. Safe state: all
   contactors de-energised.

## Faults

As F04.MOTOR.DOL: 1 no running feedback, 2 contactor stuck, 3 overload.

## Not covered

star and delta contactors (wire it in hardware as well).
