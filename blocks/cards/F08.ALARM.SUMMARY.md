# F08.ALARM.SUMMARY · `RB_AlarmSummary`

**Family:** F08 alarms and events · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Summarises up to 32 alarms (`RB_Alarm` states) for the operator: how many
are active and unacknowledged, a common alarm lamp, a horn and the alarm
that came first.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `States` | in | ARRAY[1..32] OF `RB_ALARM_STATE` | | the alarms' `State` |
| `Used` | in | DWORD | 16#FFFFFFFF | bit k−1 set: alarm k is used |
| `Silence` | in | BOOL | FALSE | rising edge stops the horn |
| `Blink` | in | TIME | T#500ms | half period of the flashing lamp |
| `Active` | out | INT | | alarms active, acknowledged or not |
| `Unacked` | out | INT | | alarms waiting for acknowledgement (active or returned) |
| `Lamp` | out | BOOL | | flashing while any is unacknowledged, steady while any is active |
| `Horn` | out | BOOL | | new unacknowledged alarm, until silenced |
| `FirstOut` | out | INT | | the first alarm since all were normal; 0: none |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F08.summary.counts]** `Active` counts used alarms in `ActiveUnack` or
   `ActiveAcked`; `Unacked` counts `ActiveUnack` and `ReturnedUnack`.
2. **[F08.summary.lamp]** While any alarm is unacknowledged the lamp
   flashes, starting lit, toggling every `Blink`; otherwise it is steady on
   while any is active, off when none is.
3. **[F08.summary.horn]** Each increase of `Unacked` sounds the horn; a
   rising edge of `Silence`, or no unacknowledged alarm left, stops it.
4. **[F08.summary.first-out]** `FirstOut` is the first used alarm to become
   active while it was 0 (the lowest number when several in one call); it
   returns to 0 when every used alarm is normal and acknowledged.

## Combines with

`Ack`), lamps and horns on the panel, HMI alarm banners.

## Not covered

SCADA job), more than 32 alarms (cascade summaries).
