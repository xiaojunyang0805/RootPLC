# F12.LEVEL · `RB_LevelSwitches`

**Family:** F12 material handling and process patterns · **Level:** L3
equipment function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Pump control from level switches, the most common small pumping job: a
sump or pit emptied (start at high, stop at low) or a tank filled (start
at low, stop at high), with high-high and low-low protection and a
run-time limit.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Fill` | in | BOOL | FALSE | FALSE: empty (sump); TRUE: fill (tank) |
| `LowLowSw`, `LowSw`, `HighSw`, `HighHighSw` | in | BOOL | FALSE | TRUE when the liquid is at or above the switch |
| `Enable` | in | BOOL | TRUE | FALSE: pump off |
| `MaxRunTime` | in | TIME | T#0s | longest run; T#0s: no limit |
| `Reset` | in | BOOL | FALSE | rising edge clears a fault |
| `Pump` | out | BOOL | | the pump's `AutoRun` |
| `AlarmHigh` / `AlarmLow` | out | BOOL | | at high-high / below low-low |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F12.level.empty]** Empty: the pump starts at `HighSw` and stops when
   `LowSw` clears; at `HighHighSw` it runs regardless (a failed high
   switch); below `LowLowSw` it never runs (dry run).
2. **[F12.level.fill]** Fill: the pump starts when `LowSw` clears and stops
   at `HighSw`; at `HighHighSw` it stops.
3. **[F12.level.alarms]** `AlarmHigh` at `HighHighSw`, `AlarmLow` below
   `LowLowSw`, in both modes.
4. **[F12.level.faults]** The pump running longer than `MaxRunTime` (a
   blocked pump, a leak) is fault 1; `HighSw` without `LowSw` (a switch
   failed) is fault 2. A fault stops the pump (safe state) until `Reset`.
5. **[F12.level.enable]** Disabled: pump off, the start is forgotten.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | the pump ran longer than `MaxRunTime` | `Reset` |
| 2 | high switch on with the low switch off | `Reset` after the switches agree |

## Combines with

`RB_Pump` or `RB_Motor` (`Pump` as `AutoRun`), `RB_DutyStandby` (two
pumps), `RB_Debounce` for wave-tossed switches, `RB_Alarm` on the alarm
outputs.

## Not covered

Analog level control (use `RB_OnOff` or `RB_PID`), a second pump
starting at high-high (use `RB_DutyStandby` with a demand of 2).
