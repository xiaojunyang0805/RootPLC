# F01.RAMP · `RB_Ramp`

**Family:** F01 signal conditioning · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Limits how fast a value may change (rate limiter), for example a speed or
temperature set point, with separate rates up and down.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `In` | in | REAL | | target value |
| `RiseRate` / `FallRate` | in | REAL | 0 | units per second up / down; 0: no limit |
| `Track` | in | BOOL | FALSE | TRUE: `Out` follows `In` directly |
| `Out` | out | REAL | | limited value |
| `Busy` | out | BOOL | | `Out` has not reached `In` |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F01.ramp.start]** In the first call `Out` = `In`.
2. **[F01.ramp.rate]** Each call `Out` moves towards `In` by at most
   `RiseRate · dt` up or `FallRate · dt` down (dt: time since the previous
   call) and never overshoots `In`.
3. **[F01.ramp.unlimited]** A rate of 0 lets `Out` jump to `In` in that
   direction; `Track` TRUE makes it follow at once.
4. **[F01.ramp.busy]** `Busy` is TRUE while `Out` ≠ `In`.
