# F02.TRIPS · `RB_Trips`

**Family:** F02 discrete logic and interlocks · **Level:** L1 elementary
function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Up to 16 trip conditions that stop a machine and stay latched until the
operator resets them, with the first-out, the usual answer to "why did it
stop?". Unlike `RB_Permissives`, which only block a start, trips act on a
running machine and latch.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Trip` | in | ARRAY[1..16] OF BOOL | | TRUE: trip condition present |
| `Used` | in | WORD | 16#FFFF | bit k−1 set: trip k is used |
| `Reset` | in | BOOL | FALSE | rising edge: clear the trips that have gone |
| `Ok` | out | BOOL | | no trip latched |
| `Latched` | out | WORD | | bit k−1: trip k latched |
| `Active` | out | INT | | trips latched |
| `FirstOut` | out | INT | | the first trip since all were clear; 0: none |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F02.trips.latch]** A used trip condition latches its trip; it stays
   latched after the condition goes.
2. **[F02.trips.reset]** A rising edge of `Reset` clears the latched trips
   whose condition is gone; a condition still present stays latched.
3. **[F02.trips.first-out]** `FirstOut` is the first trip to latch while
   none was latched (the lowest number when several in one call); it
   returns to 0 when all are clear.
4. **[F02.trips.unused]** Unused trips never latch and are cleared when
   taken out of use.

## Tests

`conformance/cases/blocks/ok_rb_round6.st` (`trips_*`). Library mutation score against all block tests: 99% (1233 of 1237 library mutants, 5 Nov 2026; the four survivors are equivalent mutants in `RB_MotorReversing`, `RB_AlarmSummary` and `RB_Trips`).

## Combines with

`RB_MachineState` (`NOT Ok` as `Abort`), F04 `Interlock` inputs,
`RB_AnalogLimits` and `RB_ZeroSpeed` as trip conditions, `RB_Bypass` for
maintenance, `RB_EventLog` (log `FirstOut`).

## Not covered

Trips with delays (put `RB_Alarm` or a timer before), more than 16 trips
(cascade), safety trips (a safety function on certified hardware).
