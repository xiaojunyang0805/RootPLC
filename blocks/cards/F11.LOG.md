# F11.LOG · `RB_DataLog`

**Family:** F11 data handling and communication · **Level:** L1
elementary function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Records a value at a fixed interval into a ring of the last 64 samples
and gives the minimum, maximum and average of what is stored: a short
trend for the HMI, a record of a batch or a quick diagnosis.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Value` | in | REAL | 0 | value to record |
| `Interval` | in | TIME | T#1s | time between samples |
| `Enable` | in | BOOL | TRUE | FALSE: pause |
| `Clear` | in | BOOL | FALSE | rising edge: empty the log |
| `Samples` | out | ARRAY[1..64] OF REAL | | the ring |
| `Newest` | out | INT | | index of the newest sample; 0: none |
| `Count` | out | INT | | samples stored, up to 64 |
| `Minimum` / `Maximum` / `Average` | out | REAL | | of the stored samples; 0 when empty |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F11.log.sample]** With `Enable`, a sample is taken at once when the
   log is empty, then every `Interval`.
2. **[F11.log.ring]** Samples go into a ring of 64: after 64 the oldest is
   overwritten; `Newest` points to the latest.
3. **[F11.log.stats]** `Minimum`, `Maximum` and `Average` cover the stored
   samples; with none they are 0.
4. **[F11.log.clear]** A rising edge of `Clear` empties the log.
