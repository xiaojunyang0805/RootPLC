# F04.CYLINDER · `RB_Cylinder`

**Family:** F04 device modules · **Level:** L2 device module ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Drives a pneumatic cylinder, double-acting (two solenoids) or
single-acting (one solenoid, spring return), with extended and retracted
end switches, a mode, an interlock and a permissive, and faults when a
stroke does not finish in time.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Mode` | in | `RB_MODE` | `Off` | `Off`, `Manual` or `Auto` ([blocks.mode]) |
| `AutoExtend` / `ManExtend` | in | BOOL | FALSE | TRUE extended, FALSE retracted (level) |
| `Interlock` | in | BOOL | FALSE | TRUE: both solenoids off now |
| `Permissive` | in | BOOL | TRUE | FALSE: do not extend |
| `FbExtended` / `FbRetracted` | in | BOOL | FALSE | end switches |
| `DoubleActing` | in | BOOL | TRUE | FALSE: spring return, `Retract` stays FALSE |
| `Feedback` | in | BOOL | TRUE | FALSE when no end switches are fitted |
| `MoveTime` | in | TIME | T#3s | supervision time for a stroke |
| `Reset` | in | BOOL | FALSE | rising edge clears a fault |
| `Extend` / `Retract` | out | BOOL | | solenoids A / B |
| `IsExtended` / `IsRetracted` | out | BOOL | | position from the end switches |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |
| `Status` | out | `RB_DEVICE_STATUS` | | for the HMI ([blocks.status]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F04.cyl.mode]** In `Auto` the cylinder follows `AutoExtend`, in
   `Manual` `ManExtend`. A double-acting cylinder drives `Retract` whenever
   it is active and not extending; in `Off` both solenoids are off.
2. **[F04.cyl.interlock]** `Interlock` TRUE switches both solenoids off at
   once, in every mode (a spring-return cylinder retracts; a double-acting
   one stops as its valve allows).
3. **[F04.cyl.permissive]** `Permissive` FALSE prevents extending, not
   staying extended.
4. **[F04.cyl.not-extended]** Extending, `FbExtended` not TRUE within
   `MoveTime`: fault 1.
5. **[F04.cyl.not-retracted]** Retracting (double-acting: `Retract` on;
   single-acting: active and not extending), `FbRetracted` not TRUE within
   `MoveTime`: fault 2. A single-acting cylinder is not supervised in `Off`
   or while interlocked.
6. **[F04.cyl.both]** Both end switches on for `MoveTime`: fault 3; both
   position outputs are FALSE while both switches are on.
7. **[F04.cyl.fault]** A fault latches and switches both solenoids off; a
   rising edge of `Reset` clears it.
8. **[F04.cyl.no-feedback]** With `Feedback` FALSE the position outputs
   follow the command; switching supervision on starts its timers fresh.
9. **[F04.cyl.status]** `Status.Starts` counts extensions.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | did not extend within `MoveTime` | `Reset` |
| 2 | did not retract within `MoveTime` | `Reset` |
| 3 | both end switches on | `Reset` |

clamping stations (F12), F08 alarms on `Error`, F10 mode managers.

## Not covered

end-position cushioning, two-hand control and other safety functions.
