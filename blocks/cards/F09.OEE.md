# F09.OEE · `RB_OEE`

**Family:** F09 supervision and diagnostics · **Level:** L1 elementary
function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Measures overall equipment effectiveness (OEE) of a machine over a
period: availability, performance and quality, and their product, from
the machine's running signal and its good and rejected parts.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Planned` | in | BOOL | FALSE | planned production time |
| `Running` | in | BOOL | FALSE | producing |
| `Good` / `Reject` | in | BOOL | FALSE | rising edge: one part |
| `IdealCycle` | in | TIME | T#1s | ideal time per part |
| `Reset` | in | BOOL | FALSE | rising edge: start a new period |
| `Availability` / `Performance` / `Quality` / `OEE` | out | REAL | | 0 … 1 |
| `PlannedTime` / `RunTime` | out | LREAL | | seconds in the period |
| `GoodCount` / `RejectCount` | out | UDINT | | parts in the period |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F09.oee.time]** Time counts only while `Planned`: `PlannedTime`
   always, `RunTime` while `Running` as well.
2. **[F09.oee.factors]** Availability = `RunTime` / `PlannedTime`;
   Performance = `IdealCycle` × parts / `RunTime`, at most 1; Quality =
   good / all parts; OEE = their product. A factor with nothing to divide
   by is 0.
3. **[F09.oee.reset]** A rising edge of `Reset` sets times and counts to 0.

`Reset` at shift change), `RB_Counter`, Modbus for SCADA and MES.

## Not covered

operator, history per shift (an HMI or MES job).
