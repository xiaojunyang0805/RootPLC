# F05.PHASE · `RB_Phase`

**Family:** F05 sequencing · **Level:** L1 (the state frame of a batch
phase) · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Gives a batch phase (dosing, heating, mixing, ...) the state model process
engineers know from ISA-88 (public state names only): idle, running, held,
complete, stopped, aborted, with the commands start, hold, restart, stop,
abort and reset. The phase's own logic (typically an `RB_StepChain`) runs
while the state is `Running` and reports `Finished`.

## Interface

| Name | Direction | Type | Meaning |
|---|---|---|---|
| `Start`, `Hold`, `Restart`, `Stop`, `Abort`, `Reset` | in | BOOL | commands, on their rising edge |
| `Finished` | in | BOOL | the phase logic has completed |
| `State` | out | `RB_PHASE_STATE` | `Idle`, `Running`, `Held`, `Complete`, `Stopped`, `Aborted` |
| `Running` / `Done` | out | BOOL | `State = Running` / `State = Complete` |
| `Rejected` | out | BOOL | TRUE in the call of a command that was not valid in the state |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F05.phase.transitions]** `Start`: idle → running; `Hold`: running →
   held; `Restart`: held → running; `Stop`: running or held → stopped;
   `Abort`: running, held or stopped → aborted; `Reset`: complete, stopped
   or aborted → idle; `Finished` in running → complete.
2. **[F05.phase.priority]** When several commands rise in one call, the
   first of abort, stop, hold, restart, start, reset that is valid in the
   state acts; `Finished` counts only when no command acts. (An abort in
   idle no longer swallows a start given with it; found by R2, 6 Nov 2026.)
3. **[F05.phase.rejected]** A command that is not valid in the state
   changes nothing and sets `Rejected` for that call, also when another
   command given with it acts.
4. **[F05.phase.transient]** The transient states of ISA-88 (holding,
   stopping, aborting, restarting) are not modelled; the phase logic acts
   on the state change instead.

## Tests

`conformance/cases/blocks/ok_rb_sequence.st` (`phase_*`). Library mutation score against all block tests: 99% (1259 of 1265 library mutants, 6 Nov 2026; the six survivors are equivalent mutants in `RB_MotorReversing`, `RB_AlarmSummary`, `RB_Trips` and `RB_PID`).

## Combines with

`RB_StepChain` as the phase logic (hold the chain while `Held`, abort it
when `Aborted` or `Stopped`), `RB_ModeManager`, `RB_RecipeTable` (load the
recipe with the start; see the batch-mixer template), F08 alarms that hold
or abort a phase.

## Not covered

Transient states, unit and procedure levels of ISA-88, recipe parameters
(use `RB_RecipeTable`).
