# F06.PROFILE · `RB_SetpointProfile`

**Family:** F06 closed-loop control · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Runs a set-point program of up to 8 segments, each a ramp to a target and
a soak at it: ovens, kilns, heat treatment, sterilisers, curing. The set
point feeds a controller (`RB_PID`).

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Start` | in | BOOL | FALSE | rising edge: segment 1, ramping from `PV` |
| `Hold` | in | BOOL | FALSE | TRUE: set point and timers frozen |
| `Abort` | in | BOOL | FALSE | rising edge: end the program |
| `PV` | in | REAL | 0 | process value |
| `Count` | in | INT | 1 | segments used, 1 … 8 |
| `Targets` | in | ARRAY[1..8] OF REAL | | target of each segment |
| `RampTimes` / `SoakTimes` | in | ARRAY[1..8] OF TIME | | ramp and soak time of each segment |
| `Band` | in | REAL | 0 | guaranteed soak band; 0: off |
| `SP` | out | REAL | | the set point |
| `Segment` | out | INT | | 1 … `Count`; 0: not running |
| `Soaking` / `Busy` / `Done` | out | BOOL | | program state |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F06.profile.start]** A rising edge of `Start` begins segment 1 with
   `SP` = `PV` and clears `Done`; the start call itself counts no time.
2. **[F06.profile.ramp]** In a ramp `SP` moves linearly from the previous
   target (or the start value) to the segment's target in `RampTime`; then
   the soak begins at the target. A ramp of T#0s steps to the target.
3. **[F06.profile.soak]** The soak lasts `SoakTime`; with `Band` > 0 its
   time counts only while |`PV` − `SP`| ≤ `Band` (guaranteed soak).
4. **[F06.profile.end]** After the soak of segment `Count`, `Done` is TRUE,
   `Segment` 0 and `SP` stays at the last target.
5. **[F06.profile.hold-abort]** `Hold` freezes everything; a rising edge of
   `Abort` ends the program (`SP` stays where it was).
6. **[F06.profile.count]** A start with `Count` outside 1 … 8 is fault 1:
   the program does not run. Times add up exactly (TIME, no rounding).

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | `Count` outside 1 … 8 | a start with a valid `Count` |

## Combines with

`RB_PID` (`SP`), `RB_RecipeTable` (targets and times from a recipe),
`RB_Phase` (Hold and Abort with the batch), `RB_DataLog` (the record).

## Not covered

Ramps given as a rate instead of a time, more than 8 segments, jumps
and loops in the program, ramp holdback (pausing the ramp when PV lags).
