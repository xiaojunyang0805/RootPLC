# F11.FIFO · `RB_Fifo`

**Family:** F11 data handling · **Level:** L1 elementary function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Keeps up to 32 values in arrival order: part IDs on a conveyor, order
codes, test results waiting for a station. The oldest comes out first.

## Interface

| Name | Direction | Type | Meaning |
|---|---|---|---|
| `Put` / `InValue` | in | BOOL / DINT | rising edge appends `InValue` |
| `Get` | in | BOOL | rising edge takes the oldest into `OutValue` |
| `Clear` | in | BOOL | rising edge empties the queue |
| `Reset` | in | BOOL | rising edge clears an error |
| `OutValue` | out | DINT | the value last taken |
| `First` | out | DINT | the oldest value, without taking it (0 when empty) |
| `Count` / `Empty` / `Full` | out | INT / BOOL / BOOL | fill state |
| `Error` / `ErrorID` | out | BOOL / UDINT | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F11.fifo.order]** Values come out in the order they were put in.
2. **[F11.fifo.same-call]** A get and a put in one call: the get takes the
   oldest value first, then the new value is appended.
3. **[F11.fifo.full]** A put on a full queue (32) is fault 1 and the value
   is dropped; a get on an empty queue is fault 2. Faults latch until
   `Reset`.
4. **[F11.fifo.clear]** `Clear` empties the queue.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | put on a full queue (value dropped) | `Reset` |
| 2 | get on an empty queue | `Reset` |
