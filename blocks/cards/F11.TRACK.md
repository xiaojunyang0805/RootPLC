# F11.TRACK · `RB_ShiftTrack`

**Family:** F11 data handling and communication · **Level:** L1
elementary function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Tracks parts on a conveyor with a shift register of 64 positions (one per
pitch, encoder step or chain link): an inspection station enters a code
at position 1, and an ejector or a later station acts when the entry
reaches its position. The classic reject system.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Shift` | in | BOOL | FALSE | rising edge: every entry one position on |
| `InValue` | in | DINT | 0 | entry for position 1 at the shift (0: no part) |
| `ReadPos` | in | INT | 10 | position of the ejector or station, 1 … 64 |
| `Remove` | in | BOOL | FALSE | rising edge: clear the entry at `ReadPos` |
| `Clear` | in | BOOL | FALSE | rising edge: clear all |
| `Positions` | out | ARRAY[1..64] OF DINT | | the register |
| `AtRead` | out | DINT | | the entry at `ReadPos` |
| `Occupied` | out | INT | | non-zero entries |
| `Error` / `ErrorID` | out | BOOL / UDINT | | settings fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F11.track.shift]** On a rising edge of `Shift` each entry moves one
   position on, the entry at 64 drops out, and `InValue` goes into
   position 1.
2. **[F11.track.read]** `AtRead` is the entry at `ReadPos`; a rising edge
   of `Remove` clears it there (the part was ejected or processed).
3. **[F11.track.clear]** A rising edge of `Clear` empties the register.
4. **[F11.track.settings]** `ReadPos` outside 1 … 64 is fault 1: `AtRead`
   0 and `Remove` ignored; shifting goes on.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | `ReadPos` outside 1 … 64 | a valid `ReadPos` |

## Combines with

`RB_Debounce` or an encoder pulse for `Shift`, `RB_Cylinder` (the
ejector on `AtRead`), `RB_Fifo` (part data in order), `RB_Diverter`.

## Not covered

Several read positions (use several blocks on the same shift, or read
`Positions`), more than 64 positions, encoder counting itself.
