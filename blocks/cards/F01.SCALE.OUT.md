# F01.SCALE.OUT · `RB_ScaleOut`

**Family:** F01 signal conditioning · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Converts an engineering value (%, Hz, bar) into the integer word of an
analog output module, the reverse of `RB_Scale`, with limiting and a
fail-safe value for faults.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Value` | in | REAL | 0 | engineering value |
| `EngMin` / `EngMax` | in | REAL | 0 / 100 | engineering range (may be reversed) |
| `RawMin` / `RawMax` | in | REAL | 0 / 27648 | output word range |
| `Fault` | in | BOOL | FALSE | TRUE: output `FailValue` |
| `FailValue` | in | REAL | 0 | engineering value on a fault |
| `Raw` | out | INT | | the output word |
| `Limited` | out | BOOL | | the value was outside the range |
| `Error` / `ErrorID` | out | BOOL / UDINT | | settings fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F01.scale-out.map]** `Raw` = `RawMin` + (v − `EngMin`) ×
   (`RawMax` − `RawMin`) / (`EngMax` − `EngMin`), rounded, where v is
   `Value` limited to the engineering range; `Limited` when it was
   outside.
2. **[F01.scale-out.fault]** `Fault` TRUE uses `FailValue` instead of
   `Value` (safe state chosen per output).
3. **[F01.scale-out.settings]** `EngMin` = `EngMax` is fault 1; `Raw` is
   `RawMin` while the settings are wrong.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | `EngMin` = `EngMax` | correct settings |

## Not covered

detection (a module feature).
