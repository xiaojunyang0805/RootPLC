# F04.VALVE.ANALOG · `RB_ValveAnalog`

**Family:** F04 device modules · **Level:** L2 device module · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Drives a control valve (or damper) with a position command of 0 … 100 %,
with a mode, an interlock to a safe position and supervision of the
positioner's feedback.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Mode` | in | `RB_MODE` | `Off` | `Off`, `Manual` or `Auto` ([blocks.mode]) |
| `AutoPos` / `ManPos` | in | REAL | 0 | automatic / manual position, % |
| `Interlock` | in | BOOL | FALSE | TRUE goes to `SafePos` now, in every mode |
| `SafePos` | in | REAL | 0 | % in `Off`, on interlock and on a fault |
| `PosFb` | in | REAL | 0 | position feedback, % |
| `Feedback` | in | BOOL | TRUE | FALSE when no position feedback is wired |
| `Tolerance` | in | REAL | 5.0 | allowed deviation, % |
| `FeedbackTime` | in | TIME | T#10s | supervision time |
| `Reset` | in | BOOL | FALSE | rising edge clears a fault |
| `Out` | out | REAL | | position command, limited to 0 … 100 % |
| `Pos` | out | REAL | | position, from the feedback (the command without feedback) |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |
| `Status` | out | `RB_DEVICE_STATUS` | | for the HMI ([blocks.status]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F04.valve-analog.mode]** In `Auto` the command follows `AutoPos`, in
   `Manual` `ManPos`, in `Off` it is `SafePos`; always limited to 0 … 100 %.
2. **[F04.valve-analog.interlock]** `Interlock` TRUE sets `SafePos` at once,
   in every mode.
3. **[F04.valve-analog.deviation]** The feedback deviating from the command
   by more than `Tolerance` for `FeedbackTime` is fault 1.
4. **[F04.valve-analog.signal]** Feedback below −10 % or above 110 % (a
   broken wire on a 4–20 mA signal, scaled) is fault 2 at once.
5. **[F04.valve-analog.fault]** A fault latches and sets `SafePos` (safe
   state, chosen per valve: closed by default, 100 % for a valve that must
   open). A rising edge of `Reset` clears it; switching `Feedback` on
   starts the supervision timer fresh.
6. **[F04.valve-analog.status]** `Status.Commanded` is a command above 0 %,
   `Status.Active` a position above `Tolerance`; `Status.Starts` counts
   openings from 0 %.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | position deviates from the command for `FeedbackTime` | `Reset` |
| 2 | feedback signal out of range | `Reset` after the signal is back |

## Combines with

`RB_PID` (its `Out` as `AutoPos`), `RB_SplitRange` (two valves on one
controller), `RB_Scale` for the feedback, `RB_Ramp` for a slow opening, F08
alarms on `Error`.

## Not covered

Positioner diagnostics over HART or a fieldbus, valve characteristic
linearisation, stroke testing.
