# F03.SCHEDULE · `RB_Schedule`

**Family:** F03 timing, counting, scheduling · **Level:** L1 elementary
function · **Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

A weekly time switch: on between `OnTime` and `OffTime` on selected days
(lighting, ventilation, heating set-back, shift operation). A window
across midnight is supported and belongs to the day it starts.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Now` | in | TOD | | time of day, from the controller's clock |
| `Day` | in | INT | 1 | weekday, 1 Monday … 7 Sunday |
| `OnTime` / `OffTime` | in | TOD | 06:00 / 22:00 | the window |
| `Days` | in | BYTE | 16#7F | bit d−1 set: day d selected |
| `Enable` | in | BOOL | TRUE | FALSE: off |
| `Out` | out | BOOL | | in the window on a selected day |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F03.schedule.window]** With `OnTime` < `OffTime`, `Out` from `OnTime`
   up to (not including) `OffTime`; with `OnTime` = `OffTime` never.
2. **[F03.schedule.overnight]** With `OnTime` > `OffTime`, `Out` from
   `OnTime` to midnight and from midnight up to `OffTime`; the part after
   midnight counts for the day before (Monday night into Tuesday follows
   Monday's bit; Sunday into Monday follows Sunday's).
3. **[F03.schedule.days]** Only on days selected in `Days`, and only with
   `Enable`.
4. **[F03.schedule.day]** `Day` outside 1 … 7 is fault 1; `Out` FALSE.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | `Day` outside 1 … 7 | a valid day |

## Combines with

(request Auto at shift start), F06 set-point switching.

## Not covered

Holidays and exception days, several windows per day (use several
blocks), the clock itself (the application reads the controller's real
time clock and the weekday).
