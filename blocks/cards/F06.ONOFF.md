# F06.ONOFF · `RB_OnOff`

**Family:** F06 closed-loop control · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Switches a heater, cooler or pump on and off around a set point with a
hysteresis band, so the output does not chatter (thermostat, level
control between two points).

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Enable` | in | BOOL | FALSE | FALSE: `Out` FALSE |
| `SP` / `PV` | in | REAL | | set point / process value |
| `Hysteresis` | in | REAL | 1.0 | total band around `SP` (sign ignored) |
| `Direct` | in | BOOL | FALSE | FALSE heating, TRUE cooling |
| `Out` | out | BOOL | | on/off command |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F06.onoff.heating]** Heating: on when `PV ≤ SP − Hysteresis/2`, off
   when `PV ≥ SP + Hysteresis/2`, unchanged in between.
2. **[F06.onoff.cooling]** Cooling: on when `PV ≥ SP + Hysteresis/2`, off
   when `PV ≤ SP − Hysteresis/2`.
3. **[F06.onoff.enable]** `Enable` FALSE switches the output off.
