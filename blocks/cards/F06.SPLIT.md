# F06.SPLIT · `RB_SplitRange`

**Family:** F06 closed-loop control · **Level:** L1 elementary function ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Splits one controller output over two actuators: two valves in sequence
for a wide range, or heating and cooling on one temperature controller.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `In` | in | REAL | 0 | controller output, % |
| `SplitPoint` | in | REAL | 50.0 | % where A ends and B begins |
| `Deadband` | in | REAL | 0 | % between A and B, centred on `SplitPoint` |
| `InvertA` | in | BOOL | FALSE | A runs 100 → 0 % as `In` rises |
| `OutA` / `OutB` | out | REAL | | actuator commands, 0 … 100 % |
| `Error` / `ErrorID` | out | BOOL / UDINT | | settings fault ([blocks.fault]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F06.split.ranges]** With lo = `SplitPoint` − `Deadband`/2 and hi =
   `SplitPoint` + `Deadband`/2: `OutA` goes 0 → 100 % as `In` goes 0 → lo
   (100 → 0 % with `InvertA`); `OutB` goes 0 → 100 % as `In` goes hi → 100.
   Both are limited to 0 … 100 %.
2. **[F06.split.settings]** lo ≤ 0 or hi ≥ 100 leaves no range: fault 1,
   both outputs 0 (safe state) while the settings are wrong.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | `SplitPoint` and `Deadband` leave no range for A or B | correct settings |

## Combines with

## Not covered

Different gains per range, overlap instead of a dead band, more than two
actuators (cascade two blocks).
