# F04.VALVE.ONOFF · `RB_ValveOnOff`

**Family:** F04 device modules · **Level:** L2 device module ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Drives an on/off valve (one solenoid output) with open and closed limit
switches, a mode, an interlock and a permissive, and faults when the valve
does not do what it was told.

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Mode` | in | `RB_MODE` | `Off` | `Off`, `Manual` or `Auto` ([blocks.mode]) |
| `AutoOpen` | in | BOOL | FALSE | automatic command (level) |
| `ManOpen` | in | BOOL | FALSE | manual command (level) |
| `Interlock` | in | BOOL | FALSE | TRUE closes now, in every mode |
| `Permissive` | in | BOOL | TRUE | FALSE: do not open |
| `FbOpen` / `FbClosed` | in | BOOL | FALSE | limit switches |
| `Feedback` | in | BOOL | TRUE | FALSE when no limit switches are fitted |
| `FeedbackTime` | in | TIME | T#5s | supervision time |
| `Reset` | in | BOOL | FALSE | rising edge clears a fault |
| `Open` | out | BOOL | | solenoid output |
| `IsOpen` / `IsClosed` | out | BOOL | | position from the feedback |
| `Error` / `ErrorID` | out | BOOL / UDINT | | fault ([blocks.fault]) |
| `Status` | out | `RB_DEVICE_STATUS` | | for the HMI ([blocks.status]) |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F04.valve.mode]** In `Auto` the valve follows `AutoOpen`, in `Manual`
   `ManOpen`, in `Off` it is closed.
2. **[F04.valve.interlock]** `Interlock` TRUE closes the valve at once, in
   every mode, for as long as it is TRUE.
3. **[F04.valve.permissive]** `Permissive` FALSE prevents opening; it does
   not close a valve that is already open.
4. **[F04.valve.not-opened]** Commanded open, `FbOpen` not TRUE for
   `FeedbackTime`: fault 1.
5. **[F04.valve.not-closed]** Commanded closed, `FbClosed` not TRUE for
   `FeedbackTime`: fault 2.
6. **[F04.valve.conflict]** `FbOpen` and `FbClosed` both TRUE for
   `FeedbackTime`: fault 3; `IsOpen` and `IsClosed` are both FALSE.
7. **[F04.valve.fault]** A fault latches and closes the valve (safe state:
   de-energised). A rising edge of `Reset` clears it; if the cause remains,
   it is detected again after `FeedbackTime`.
8. **[F04.valve.no-feedback]** With `Feedback` FALSE there is no
   supervision and `IsOpen` / `IsClosed` follow the command. Switching
   supervision on starts its timers fresh.
9. **[F04.valve.status]** `Status.Starts` counts the openings; `Status`
   mirrors mode, command, position and fault.

## Faults

| ErrorID | Meaning | Cleared by |
|---|---|---|
| 1 | did not open within `FeedbackTime` | `Reset` |
| 2 | did not close within `FeedbackTime` | `Reset` |
| 3 | both limit switches TRUE | `Reset` |

## Combines with

F05 step chains (open, wait for `IsOpen`), F12 tank filling and dosing, F08
alarms on `Error`, F10 mode managers driving `Mode`.

## Not covered

Analog (positioning) valves; valves with two solenoids (open and close
coils); end-position hold-off times after a command; safety shut-off (a
safety function, which belongs on certified hardware).
