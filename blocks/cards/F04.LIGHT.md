# F04.LIGHT · `RB_Light`

**Family:** F04 device modules · **Level:** L2 device module ·
**Library:** RootBlocks 0.1.0 · **Conventions:** spec/15-blocks.md

## Job

Switches a lamp or light: indicator lamps on panels, machine lights,
building and stairwell lights. Push-button toggle, on and off commands, an
optional time after which the light switches off by itself, flashing, lamp
test, an interlock and maintenance counters. In real code this is the most
common device module (corpus classifier, F04 by kind).

## Interface

| Name | Direction | Type | Default | Meaning |
|---|---|---|---|---|
| `Toggle` | in | BOOL | FALSE | rising edge: on ↔ off |
| `SetOn` / `SetOff` | in | BOOL | FALSE | rising edge: on / off; off wins |
| `OnTime` | in | TIME | T#0s | off by itself after this; T#0s: stays on |
| `Flash` | in | BOOL | FALSE | flash while on |
| `FlashTime` | in | TIME | T#500ms | half period of the flashing |
| `LampTest` | in | BOOL | FALSE | output on whatever the state |
| `Interlock` | in | BOOL | FALSE | off now and stays off ([blocks.interlock]) |
| `Out` | out | BOOL | | lamp output |
| `IsOn` | out | BOOL | | switched on (also in the dark phase of flashing) |
| `Remaining` | out | TIME | | time until it switches off by itself |
| `Switchings` | out | UDINT | | switch-ons since the block started |
| `BurnTime` | out | LREAL | | seconds the output was on |

Inputs keep their last value between calls (IEC 61131-3 function-block
inputs), so pass every input that changes, in every call.

## Behaviour rules

1. **[F04.light.commands]** A rising edge of `SetOff` (or `Interlock`)
   switches off; otherwise a rising edge of `SetOn` switches on; otherwise
   a rising edge of `Toggle` changes the state.
2. **[F04.light.timer]** With `OnTime` > 0 the light switches off after
   `OnTime`; `SetOn`, or `Toggle` switching on, starts the time again (a
   stairwell button pressed again extends the light).
3. **[F04.light.flash]** While on with `Flash`, `Out` flashes with
   `FlashTime` on and off, starting on.
4. **[F04.light.test]** `LampTest` sets `Out` regardless of the state; the
   state is unchanged.
5. **[F04.light.counters]** `Switchings` counts switch-ons; `BurnTime` adds
   the time `Out` was on (for lamp replacement and maintenance).

`conformance/cases/blocks/ok_rb_light.st` (`light_*`). Library mutation score against all block tests: 99% (1258 of 1262 library mutants, 5 Nov 2026; the four survivors are equivalent mutants in `RB_MotorReversing`, `RB_AlarmSummary` and `RB_Trips`).

## Combines with

`RB_Debounce` (push buttons), `RB_Schedule` (switch on by time of day),
`RB_AlarmSummary` (alarm lamps), `RB_RunHours` (maintenance intervals),
`RB_MachineState` (status lamps).

## Not covered

Dimming (an analog output: `RB_Ramp` with `RB_ScaleOut`), DALI and KNX
lighting buses, traffic-light sequences (`RB_Drum` or `RB_StepChain`), a
warning before a timed light goes off.
