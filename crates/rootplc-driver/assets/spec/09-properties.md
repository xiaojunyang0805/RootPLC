# Pragmas and verification properties

*Status: not started.*

Pragmas RootPLC defines so far (all others are warning RP0013, see 01-lexical):

| Pragma | Meaning |
|---|---|
| `{attribute 'name'}` / `{attribute 'name' := 'value'}` | Attach an attribute to the next declaration (CODESYS-compatible form) |

Verification properties (input to `rootplc verify`) will be defined here in Phase 2.
